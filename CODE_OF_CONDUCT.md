# Código de conducta

Este proyecto busca una colaboración respetuosa, inclusiva y centrada en el
trabajo técnico.

Se espera que todas las personas participantes:

- mantengan un tono profesional y constructivo;
- acepten revisiones técnicas de buena fe;
- respeten la privacidad y no publiquen datos sensibles;
- eviten acoso, discriminación, ataques personales o contenido sexualizado;
- informen de problemas de seguridad por el canal privado descrito en
  `SECURITY.md`.

El mantenedor puede editar o retirar contribuciones y restringir la
participación ante conductas contrarias a estas normas. Los incidentes de
conducta pueden comunicarse de forma privada mediante el perfil del mantenedor
del repositorio.
